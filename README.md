# Weather Data Analysis

## 📌 Project Overview

Weather Data Analysis is a data analytics project that analyzes
weather-related data using Python, Jupyter Notebook and Power BI.

## 🎯 Objectives

- Analyze weather data
- Identify weather patterns
- Perform data cleaning and preprocessing
- Generate meaningful insights
- Visualize the results using Power BI

## 🛠️ Technologies Used

- Python
- Jupyter Notebook
- Pandas
- NumPy
- Matplotlib
- Power BI

## 📂 Project Files

- `Weather_Data_Analysis.ipynb` - Python data analysis
- `Weather Data Analysis.pbip` - Power BI project
- Screenshots - Project dashboard/output

## 📊 Features

- Data preprocessing
- Exploratory Data Analysis
- Weather trend analysis
- Data visualization
- Interactive Power BI dashboard

## 🚀 Future Improvements

- Add weather prediction using Machine Learning
- Add real-time weather API integration
- Create advanced weather forecasting models
